# VELMOR PERFUMES — сайт магазина

Next.js 15 · TypeScript · Tailwind CSS. Интерфейс RU / UZ (латиница), заказ через Telegram.

## Запуск

```powershell
npm install
npm run build
npm start
```
Откройте http://localhost:3000. Режим разработки с автообновлением: `npm run dev`.

## Где что менять

| Что | Файл |
|---|---|
| Цены и объёмы (сетки A/B) | `src/data/catalog.ts` → `PRICE_GROUPS` |
| Товары, фото, alt-тексты, черновики | `src/data/catalog.ts` → `products` |
| Ароматы на главной | `src/data/catalog.ts` → `featuredSlugs` |
| Ноты, аккорды, год, парфюмер (Fragrantica.ru) | `src/data/fragrance-info.ts` |
| Telegram-канал и контакт менеджера | `src/config/store.ts` |
| Тексты интерфейса RU / UZ | `src/i18n/dictionaries.ts` |
| Файлы фотографий | `public/images/products/` (пропорции любые, кадр 4:5 задаётся через `position`) |

Внутренние заметки владельца лежат в файле `OWNER_NOTES.md` на компьютере владельца. В репозиторий он не загружается.

## Заказы в Telegram (@Patrick_1208)

В корзине покупатель указывает **имя и телефон** (обязательно), а также Telegram и комментарий (необязательно).

**Пока бот не настроен:** кнопка «Написать менеджеру @Patrick_1208» копирует готовый заказ с данными покупателя
и открывает чат с менеджером. Покупатель отправляет сообщение сам.

**Автоматическая отправка (рекомендуется).** Сайт не может написать пользователю Telegram сам: это делает бот.
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → скопируйте **токен**.
2. **@Patrick_1208** открывает созданного бота и нажимает **Start** (бот не может написать первым).
3. Создайте файл `.env.local` по образцу `.env.example` и вставьте токен в `TELEGRAM_BOT_TOKEN=`.
4. Выполните `npm run telegram:chat-id`, скопируйте строку `TELEGRAM_CHAT_ID=…` для @Patrick_1208 в `.env.local`.
5. Перезапустите сайт: `npm run build`, затем `npm start`.

После этого в корзине появится кнопка «Отправить заказ». Заказ с именем, телефоном, составом и суммой приходит
Patrick_1208 от бота, а покупатель видит «Заказ отправлен». Цены пересчитываются на сервере по каталогу.
Токен храните только в `.env.local`: этот файл не публикуется (он в `.gitignore`).
